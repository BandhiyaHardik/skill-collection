# Using Superpowers

Choose a workflow for the user's current development task. Use a Codex skill mention such as `$systematic-debugging` or find the skill in the desktop picker. Use the tools available in this session.

| Task | Skill |
| --- | --- |
| Work through an unclear design | [$brainstorming](../brainstorming/SKILL.md) |
| Turn requirements into a multi-step plan | [$writing-plans](../writing-plans/SKILL.md) |
| Carry out a plan yourself | [$executing-plans](../executing-plans/SKILL.md) |
| Carry out a plan with delegated implementation and reviews | [$subagent-driven-development](../subagent-driven-development/SKILL.md) |
| Split independent investigations | [$dispatching-parallel-agents](../dispatching-parallel-agents/SKILL.md) |
| Trace a bug or failing test | [$systematic-debugging](../systematic-debugging/SKILL.md) |
| Implement a change using red, green, refactor | [$test-driven-development](../test-driven-development/SKILL.md) |
| Get or respond to code review | [$requesting-code-review](../requesting-code-review/SKILL.md) or [$receiving-code-review](../receiving-code-review/SKILL.md) |
| Verify a result or finish a branch | [$verification-before-completion](../verification-before-completion/SKILL.md) or [$finishing-a-development-branch](../finishing-a-development-branch/SKILL.md) |
| Inspect a session where a Superpowers workflow went poorly | [$diagnosing-superpowers](../diagnosing-superpowers/SKILL.md) |

Read [Codex tool notes](references/codex-tools.md) if worktrees or delegation are involved. Follow the user's request and project instructions to decide how much process the work needs.
